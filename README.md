## Deen Pulse Image

Place your Deen Pulse image inside:

assets/deen-pulse.png

The image should preferably be square.

Example:

assets/
    deen-pulse.png

## GitHub Pages

Upload these files to your GitHub repository:

index.html
style.css
script.js
README.md
assets/deen-pulse.png


Then:

GitHub Repository
        ↓
Settings
        ↓
Pages
        ↓
Deploy from a branch
        ↓
main
        ↓
/ (root)
        ↓
Save


GitHub will provide your website URL.
